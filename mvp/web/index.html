J5 · Console de chargement

Contrôler le bon, peser, sceller

Le bon est présenté par son QR signé ou par son code de retrait. Le poids pesé entre dans le dossier de preuve. Une seule utilisation est possible.

J6 · Instruction des litiges

Qui paie les manquants

Un écart hors tolérance ou un scellé rompu ouvre un litige. Il est instruit par une décision motivée, avec un montant retenu et un montant libéré. Rien ne se corrige en silence.
